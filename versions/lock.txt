# Locked upstream dependency revisions.
#
# WHY THIS FILE EXISTS
# --------------------
# A branch name is not a version. Fetching `18.0` gives you whatever the branch
# head happens to be that afternoon, so the same code produces different payroll
# numbers on different days and an upstream commit becomes indistinguishable
# from our own bug. Every repo below is pinned to an exact commit.
#
# `ops/fetch_deps.sh` checks out these SHAs, not the branch, and fails if what it
# finds on disk does not match. To move a pin deliberately, edit the SHA here and
# re-run `make oca`; never re-pin as a side effect of a failing build.
#
# Recorded 2026-10-05 by cloning each repository and reading the module
# __manifest__.py at the pinned commit.
#
# FORMAT
# ------
#   repo | ref | sha | module=version:license,module=version:license
#
# The licence of every module is recorded because the project prohibits Odoo
# Enterprise code outright (versions/pinned.env ODOO_EE_ABSENT), and the only
# reliable way to notice an OPL/EE module appearing in an otherwise LGPL/AGPL
# repository is to check the manifest rather than trust the repository's name.
